# Vision Fullstack

Projeto convertido do HTML enviado para **React + Node.js + Express + Tailwind CSS**.

## Como rodar

```bash
npm run install-all
npm run dev
```

Abra:

```txt
http://localhost:5173
```

Backend:

```txt
http://localhost:5000/api/health
```

## Funcionalidades

- Layout fiel ao Vision
- React + Tailwind CSS
- Node.js + Express
- Menu responsivo
- Seção ativa na navbar
- Botões funcionais com WhatsApp/e-mail
- Planos clicáveis com mensagens personalizadas
- Emojis trocados por ícones SVG
- Dashboard mock visual mantido no estilo original
